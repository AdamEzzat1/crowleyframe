Each helper is timed end to end against the Polars a user would write by hand for the same job. Before timing, the helper's result is checked against the hand-written result where the two are comparable. Times are median (min-max); the min is the best run. Ratio = crowley median / raw median; best-run ratio compares the fastest run of each.

Kinds: **lazy** helpers only extend the plan (timed as build + collect); **eager** helpers run a query themselves; **schema** helpers read the schema or plan only and are timed in microseconds.

## Notes on the comparisons

- `profile_diff`: raw side computes the two profiles only, not the comparison
- `explain_plan`: both sides build the six-verb pipeline and explain it
- `audit`: raw side only builds the pipeline; Polars has no audit trail
- `lineage`: raw side only builds the pipeline; Polars has no lineage
- `safe_join (eager checks)`: crowley runs join_diagnostics first, then the join; raw uses Polars' built-in m:1 validation
- `detect_drift`: raw side computes both sets of statistics only, not the comparison
- `snapshot`: crowley also writes the metadata file

## Correctness

Every helper agreed with its hand-written Polars equivalent at every size.
